# Agent notes — Mint language (public)

Mint is the public language, CLI, editor tooling, and Integration Protocol.
This repository is the public extract. SpecMint Platform
(`opsdevcode/specmint-platform`) is the governed runtime. The hosted SpecMint
service stays private. `opsdevcode/specmint` remains internal.

Do not add `mint apply`, live providers, CUE, HTTP serve, or a hosted
integration registry. Compile stays deterministic and offline. This release
is public preview / alpha, not production-ready and not 1.0.
