# Mint

Mint is a standalone specification language for saying what an engineering
system should accomplish. The public extract is an offline, deterministic
CLI (`mint`), `MintIR`, Integration Protocol v0, a conformance suite, and a
VS Code/Cursor extension.

**Public preview / alpha. Not production-ready. Not 1.0.**

Mint does not require SpecMint, Repave, Overpass, Toll, Dispatch, Relay, or
any hosted service. There is no `mint apply`. Planning never grants
execution authority. Compile and plan stay fail-closed and offline.
