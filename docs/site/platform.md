# Platform (optional)

Mint is independently usable. SpecMint Platform is an optional governed
runtime that can consume `MintIR` after the language compile and plan.

Mint does **not** require:

- SpecMint Platform or the hosted SpecMint service
- Repave, Overpass, Toll, Dispatch, or Relay
- a control plane, grant service, or live provider

Install SpecMint in a **separate** environment if you want approval,
fake/local execution, verification, and evidence. Both packages currently
expose a `mint` script; do not install them over each other.

- [SpecMint Platform](https://github.com/opsdevcode/specmint-platform)
- [Standalone boundary](../standalone.md)
- [Commercial funnel](https://opsdevco.de/products/mint)

`opsdevcode/specmint` remains internal. This language extract does not
evaluate or apply automation.
