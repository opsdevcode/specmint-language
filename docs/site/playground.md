# Playground

There is no in-browser Mint compiler and no hosted `mint apply` lab.

Walk captured compiler output on the existing OpsDevCode labs. Those pages
are truthful walkthroughs, not a live language runtime:

- [Labs hub](https://opsdevco.de/labs)
- [Create](https://opsdevco.de/labs/create)
- [Observe](https://opsdevco.de/labs/observe)
- [Reclaim](https://opsdevco.de/labs/reclaim)

For a real compile, use the [ten-minute quickstart](../quickstart.md) on
your machine. The CLI stays offline. It does not open a playground backend.
