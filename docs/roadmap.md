# Public roadmap boundaries

This page states what alpha.2 includes and what is explicitly deferred.
It is not a delivery schedule.

## In this public preview

- Offline Mint compiler, CLI, and editor
- Integration Protocol v0 and the `local.sandbox` reference integration
- SpecMint Platform as a separate public runtime
  ([opsdevcode/specmint-platform](https://github.com/opsdevcode/specmint-platform))
- Local / fake execution only

## Deferred (not claimed)

- Hosted integration registry
- Signing and OCI delivery of integrations
- Production trust service
- Live AWS, Azure, GCP, Kubernetes, GitHub, or SaaS mutation from Mint
- `mint apply`
- Custom docs hostname `mint.opsdevco.de` until DNS/hosting is owned
- VS Code Marketplace and Open VSX publication (GitHub Releases are the
  canonical VSIX source)
- A 1.0 or production-ready release

The next community program after this launch is integration authoring
and conformance, not a hosted registry in this slice.
