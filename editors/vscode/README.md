# Mint Language (VS Code)

Publisher `opsdevcode.mint-language`. Starts `mint lsp` over stdio.
Apache-2.0. The packaged version matches the language release in
`package.json`.

Install from the VSIX on the newest
[GitHub prerelease](https://github.com/opsdevcode/specmint-language/releases)
(not a `latest` tag). Download `mint-language-*.vsix` and `SHA256SUMS`,
verify the checksum, then:

- Command Palette → Extensions: Install from VSIX…
- or `code --install-extension mint-language-*.vsix`
- or `cursor --install-extension mint-language-*.vsix`

VS Code Marketplace and Open VSX publication is deferred. GitHub Releases
are the canonical VSIX source.
